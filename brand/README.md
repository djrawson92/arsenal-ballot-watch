# X profile images

- `logo-1000.png`: profile picture (X crops it to a circle)
- `header-1500x500.png`: banner (the profile picture covers its bottom-left corner)

Edit `logo.html`, `header.html`, `icon.svg` or `brand.css`, then re-render with `node brand/render.cjs` (needs Playwright).

Fonts: Oswald and Inter, both under the SIL Open Font License (see `fonts/`).
